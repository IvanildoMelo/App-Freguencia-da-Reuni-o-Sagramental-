​📊 App Frequência Reunião Sacramental
​Um aplicativo web simples, responsivo e eficiente para gerenciar a frequência das organizações durante a Reunião Sacramental. Desenvolvido para facilitar o trabalho de secretários e líderes, permitindo o registro rápido e o envio de relatórios via WhatsApp.
​🚀 Funcionalidades
​Contagem em Tempo Real: Botões de adicionar (+) e remover (-) para cada organização (Quórum de Élderes, Sociedade de Socorro, Moças, Rapazes e Primária).
​Histórico de Registros: Salve os dados localmente no navegador com data e hora para consulta posterior.
​Envio via WhatsApp: Gera automaticamente um relatório formatado e abre o WhatsApp para envio imediato.
​Persistência de Dados: Os números não se perdem ao fechar ou atualizar a página (utiliza localStorage).
​Design Moderno: Interface limpa em tons de azul e branco, otimizada para dispositivos móveis.
​🛠️ Tecnologias Utilizadas
​O projeto foi construído utilizando tecnologias web padrão, sem a necessidade de servidores externos:
​HTML5: Estruturação dos elementos e seções.
​CSS3: Estilização com foco em responsividade e estética "Clean Blue".
​JavaScript (Vanilla): Lógica de contagem, manipulação do histórico, armazenamento local e integração com a API do WhatsApp.
​📱 Como usar
​Registrar: Use os botões azuis para adicionar membros conforme eles entram na reunião.
​Gravar: Ao final da contagem, clique em "GRAVAR NO HISTÓRICO" para manter um registro salvo no aparelho.
​Enviar: Clique em "ENVIAR RELATÓRIO WHATSAPP" para compartilhar os números com a presidência ou secretários.
​Zerar: Utilize o botão "Limpar Tudo" no final da reunião para preparar o app para o próximo domingo.
